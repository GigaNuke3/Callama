Select a subject to see what it can read.

Everything a chat app should do

Plus a few things the big ones don't, because it's all running on your machine.

Memory that's actually useful

Tap "remember" on any message. Callama recalls it later by meaning, using local embeddings, so it can bring back something from weeks ago when it's relevant.

It knows who you are

Write a short bio once. It goes into every chat in every subject, so you never have to introduce yourself again.

Search everything

Search finds chats by title and by what was said in them. Pin, rename and delete chats from the sidebar.

Edit, regenerate, stop

Edit any earlier message and continue from there, regenerate the last reply, or stop a reply halfway and keep what was written.

Manage your models

Download Ollama models with a live progress bar, remove them with a two-step confirmation, and pick a different model for each chat.

Sets itself up

On Windows and Linux, if Ollama isn't installed, Callama installs it using Ollama's official installer and downloads the model that memory search needs.

Pull a model & chat

Paste a model name such as llama3.2:3b, press pull, and start talking.
